# Stock Portfolio Tracker 📈

## Description

This project is a simple **Stock Portfolio Tracker** built using Python. It allows users to create a basic stock portfolio by selecting stocks from a predefined list, entering the number of shares they own, and calculating the total investment value.

The program uses hardcoded stock prices and provides a summary of the selected stocks along with their individual values and the overall portfolio value.

## Features

- Displays a list of available stocks and their prices
- Allows users to add multiple stocks to their portfolio
- Calculates the value of each stock based on quantity
- Calculates the total investment value
- Provides a portfolio summary
- Handles invalid stock entries
- Optionally saves the portfolio summary to a text file

## Concepts Used

- Python dictionaries
- Loops and conditional statements
- User input handling
- File handling
- Arithmetic operations
- Data storage and retrieval

## Program Workflow

- A predefined collection of stocks and their prices is created.
- The user selects stocks and enters the number of shares.
- The program calculates the investment value for each stock.
- A summary of the portfolio is displayed.
- The user can save the portfolio details into a text file.

## Technologies Used

- **Programming Language:** Python

## Output

The program displays:
- Selected stocks
- Number of shares owned
- Individual stock values
- Total portfolio investment value

If enabled, the portfolio summary is also saved as a text file.
